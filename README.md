# Incoming Tone

אפליקציית Android אישית שמנגנת צליל צלצול עצמאי לשיחות נכנסות באמצעות InCallService.

## חשוב
Android לא מאפשר לאפליקציה רגילה "להשתלט" על צלצול שיחה סלולרית רק באמצעות Accessibility או Broadcast. הפתרון הנתמך הוא InCallService, ובשביל שיחות סלולריות האפליקציה צריכה להיות אפליקציית הטלפון המוגדרת כברירת מחדל.

האפליקציה אינה משתמשת בהרשאת נגישות ואינה צריכה להקליט שמע. הצליל נוצר מקומית על ידי האפליקציה בזמן אמת.

## התנהגות
- מתחיל צליל רק כאשר השיחה במצב RINGING.
- מפסיק מיד כאשר השיחה נענית/מתחילה או מנותקת.
- אינו מפעיל את הצליל לאחר מענה.
- אינו דורש Accessibility.
